# Cost Quote · 成本模型与校准飞轮

对应案例：NO.17（非标制造报价 MAPE 58.4%→9.2%）、NO.23（工程租赁报价）。
参考实现：`cases/17-quoting-engine/`。

## 何时使用

- 报价依赖老师傅"看图估"，响应慢、因人而异、经验带不走
- 报高丢单、报低亏钱的利润敏感场景
- 想把报价能力从个人变成企业资产

## 流程

1. **还原人工报价链**：跟随老师傅完整走一单（图纸→拆需求→工艺→成本→报价），
   记录每步判断依据（案例 17：报价是一条链路，不是一次心算）。
2. **显式成本模型**：材料价×重量 + 标准工时×费率×公差系数 + 表面处理 +
   批量折扣 + 管理费率——每个参数外置成"企业规则库"，财务/工艺可维护。
   这一步就把 MAPE 从经验估法拉下来（58.4%→13.2%）。
3. **禁止端到端让模型出价**：模型只做图纸信息结构化，报价必须回到企业
   规则库核算——原案例的核心教训（直接出价对不上真实成本）。
4. **校准飞轮**：规则库输出 → 人工校准 → 修正后价格回填 → 用校准样本拟合
   残差回归（岭回归，特征含工艺哑变量/数量^−0.5）。注意最小样本量：
   k 太小会过拟合，冷启动靠规则库（实测 k=30 时反而不如裸规则库）。
5. **置信分流**：图纸字段置信度低的送人工复核（送审占比 < 50% 达成
   "工作量减半"口径）。
6. **响应提速**：从"卡几天"到秒级出初稿 + 人工校准，售前不再卡死。

## 验收

- 对真实成本（或人工校准价）的 MAPE 显著低于经验估法
- 校准样本量与 MAPE 单调改善（飞轮在转的证据）
- 每个报价附成本明细（可解释、可谈判）

## 边界

- 最终对外报价与让利幅度由销售/老板决策
- 供应商价格波动需要规则库定期维护（模型不替代采购知识）
