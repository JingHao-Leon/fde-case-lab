# Content Pipeline · 内容量产流水线

对应案例：NO.15（短视频脚本，直接 AI 写可用率 0%→流水线 100%）、
NO.12（鞋服电商素材）。
参考实现：`cases/15-content-pipeline/`（违禁词零出现、日交付 400 条）。

## 何时使用

- 高峰期日产数百条文案，人工写作是产能瓶颈
- 直接让 AI 写"AI 味"重、有违禁词风险、商户/品牌间差异照顾不到

## 流程

1. **Know-how 字段化**：把优秀运营的判断拆成业务字段（客群/菜品/卖点/活动/
   语气/钩子），先结构化再谈生成——"写出一篇文案"和"稳定量产可用脚本"
   是两回事。
2. **参数化生成**：钩子×细节×卖点×CTA 组合生成，语气随字段参数变化；
   每条文案引用不同模板组合，避免同对象撞模板。
3. **校验器链**（对生成与人工稿同一口径，保证公平）：
   长度区间 → 违禁词（广告法绝对化用语，零容忍）→ 核心卖点覆盖 →
   结构完整 → 同对象查重（n-gram 相似度）。
4. **回退机制**：未过校验 → 换模板重写一次 → 仍未过 → 人工队列；
   人工只审抽检 + 回退件，角色从"写"退到"审"。
5. **反馈调优**：平台数据（留存/转化）与"味道不对"类主观反馈，定期回填为
   校验规则与参数——把语感变成可执行标准。

## 验收

- 流水线输出违禁词出现次数 = 0（红线）
- 一次可用率 ≥ 95%，人工回退率 ≤ 5%
- 同对象内容无高度重复；用同一校验器对比"直接 AI 写"基线的可用率提升

## 边界

- 品牌调性、是否发布由人工终审
- 校验词表与卖点口径需品牌方确认后固化为配置
