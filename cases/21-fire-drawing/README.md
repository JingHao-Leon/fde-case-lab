# 案例21 · 建筑消防施工图自动布置

> 对应《Datawhale FDE 案例 100》NO.21「从人工绘图到智能协作」· 技术主题：规范规则化 / 几何生成与校验 / 人机分层设计
> 方法论标签：AI 生成人决策（专业责任留给人）、分层自动化（默认参数/专家参数）、不做超规则的"创造性判断"

## 业务背景（原案例）

建筑消防施工图：数百个空间的喷淋/消火栓/灭火器布置都要对照规范判断，绘制 +
逐条规范核对要数天；AI 生成后 30 分钟出初稿。设计人员对图纸负法律责任——
所以系统边界是"按规范生成可复核的初稿"，不做超出规则的自由发挥。

## 技术问题

把规范条文变成可执行规则：空间类型 → 危险等级 →（K 值、喷头最大间距、
保护半径），然后做确定性几何布置与**可验证的覆盖校验**。

## 方案（solution.py）

- `SpecTable` 规范简表：办公=轻危险级、走廊/商铺=中危险级 I/II、车库/设备房=
  中危险级 II（K 80/115、间距 3.6/3.4/4.4 等）；
- `SprinklerPlanner`：n=ceil(边长/S_max) 网格等分、格心布头，实际间距 ≤ 上限；
  **覆盖校验用 0.5m 网格采样**——任一点到最近喷头距离 ≤ 保护半径，几何上
  确定性可复核；
- `BaselineManual` 人工习惯基线：全空间统一 4.0m 间距、不按等级调参
  （复现"因人而异"的合规风险）；
- `hydrant_layout`：消火栓沿长边布点 + 空间中心可达校验。

## 实测结果（30 个空间 / 7,506 m²）

```
方案                 合规通过率   喷头总数
人工习惯(基线)          60%       616
规范生成+几何校验       100%       631

耗时：系统 80ms（布置+逐项校验）vs 人工 10 分钟/空间 = 5 小时
```

复现：`python cases/21-fire-drawing/bench.py`

**结论**：统一间距的人工习惯在 40% 的空间产生间距超限或保护盲区（合规率
60%）——这正是案例里"不同设计人员理解差异导致质量不一致、审核要额外投入"的
量化版本。规范生成 100% 合规，总耗时从 5 小时降到 80ms（大型项目数天→
30 分钟量级）。边界明确：规范简表是演示口径，真实交付要接 GB 50084 全量条文
与设计院图签标准。

## 测试

`pytest cases/21-fire-drawing` 覆盖：K 值与危险等级匹配、间距不超上限、
全空间无保护盲区、基线违规复现（<90%）、系统 100% 合规且优于基线、
消火栓覆盖、喷头数下界、确定性。
