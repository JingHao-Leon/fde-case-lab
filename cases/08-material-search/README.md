# 案例08 · 工业 ERP 物料语义搜索与重复录入拦截

> 对应《Datawhale FDE 案例 100》NO.8「从物料难找到精准定位」· 技术主题：实体归一化 / 字符 n-gram 检索 / 主数据查重
> 方法论标签：追到根因（搜索难 → 重复录入 → 错误采购 → 报废损失）、先清洗再智能、Human-in-the-loop

## 业务背景（原案例）

工业企业 15 个团队共用老 ERP，关键词搜索弱："我明明知道库里有，就是找不到" →
重新录入 → 数据更脏 → 买错买重 → 库存积压数年后报废。AI 介入点被定义为
**数据清洗标准化 + 语义检索**——"同一个物料的不同叫法对上号"。

## 技术问题

两个业务任务：
1. **口语查询命中**："上次用的那个内六角螺栓 M8x20 国标件" → 唯一物料；
2. **重复录入拦截**：新录入变体（别名/OCR 形近字/单位后缀/旧编码前缀）在入库前识别。

## 方案（solution.py）

- `normalize()` 归一化：NFKC 全半角、单位后缀剥离、旧编码剥离、别名映射
  （圆柱头螺钉↔内六角螺栓）——这是 FDE 的真实工作量，也是检索质量的第一杠杆；
- `KeywordSearch` 老erp 式包含匹配基线；
- `NormalizedTfidf` / `FuzzyHybrid` 归一化 + TF-IDF(char 2-4) / +BM25 融合；
- `is_duplicate` 三态判定：**归一化键全等 → 自动拦截**（零误报设计）；
  模糊高分同品牌同规格（OCR 变体）→ **人工确认**；其余放行。
  品牌不同 = 正规物料不算重复、规格数字不同不算重复——这两条业务规则
  是把误拦率打到 0 的关键。

## 实测结果（1,200 唯一物料 / 587 条重复变体 / 100 条口语查询）

```
搜索方案                Top1    Top5
关键词包含(老ERP)        10%     49%
归一化+TF-IDF           100%    100%
归一化+混合检索          100%    100%    （5.3ms/次）

重复录入判定（587 条变体）：
  自动拦截(归一化键全等)   462 条 (79%)
  人工确认(模糊高分)       125 条 (21%)
  自动拦截误报             0 / 300
```

复现：`python cases/08-material-search/bench.py`

**结论**：把"圆柱头螺钉"和"内六角螺栓"对上号（归一化）带来的提升远大于换
检索器——与案例 01 的结论互相印证。查重采用"自动拦截 + 人工确认"两道闸：
归一化键全等才自动拦（误报为 0），OCR 形近字变体交人工确认，干净物料的
人工打扰率控制在 30% 以内。

## 测试

`pytest cases/08-material-search` 覆盖：归一化规则（全半角/单位/旧编码/别名）、
Top1/Top5 命中阈值、混合 > 关键词、变体全拦截 + 自动拦截零误报 + 人工率上限、
排序良构性、确定性。
