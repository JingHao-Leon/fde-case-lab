# 案例04 · 城市规划选址智能筛查

> 对应《Datawhale FDE 案例 100》NO.4「从人工研判到智能调度」· 技术主题：硬约束一票否决 / 多指标加权评分 / 可解释推荐
> 方法论标签：场景收敛（市→区→单元）、模型理解+工具计算+人决策、不迷信多智能体

## 业务背景（原案例）

规划院"识别潜力用地"：领导一句话，下面查资料、跑 GIS、跨 10 个部门讨论，
跨部门报告 3~5 天；AI 试点后 10~20 分钟出可推敲报告。关键取舍：**规则交给
规则引擎、计算交给专业工具、人负责最终决策**——不搞"多智能体博弈"。

## 技术问题

候选地块（200 块）筛选：硬约束（历史文化保护线/生态红线/断裂带）一票否决，
软指标（面积/道路/管网/污水/公服/成本）归一化加权 → Top-10 推荐，每块附依据。

## 方案（solution.py）

- `SiteScreener.screen`：硬约束零漏筛 → 软指标归一化 → 默认权重评分 →
  Top-K + 淘汰明细 + 报告文本（"一文一图一表"的文）；
- 权重外置可调（默认权重 ≠ 专家权重，检验指标体系的稳健性）；
- `spearman / topk_overlap`：与专家 gold 排序的一致性度量。

## 实测结果（200 块候选地块，42 块触碰硬约束）

```
Top10 与专家 gold 重合率：90%（默认权重下）
淘汰明细：42 块全部记录否决依据
筛查耗时：0.5ms（200 块全量） vs 人工 1 小时/地块
用专家权重跑全序：Spearman > 0.8
```

复现：`python cases/04-site-screening/bench.py`

**结论**：硬约束零漏筛 + 指标化评分让"20 块候选挑 10 块"从几轮跨部门会变成
毫秒级初筛 + 人工复核；推荐结果对权重扰动稳健（默认权重与专家权重 Top10
重合 90%）。空间计算在真实项目中由 GIS 工具承担（本实现以属性化指标替代，
保持同样的"规则引擎 + 依据输出"结构）。

## 测试

`pytest cases/04-site-screening` 覆盖：硬约束零漏筛、Top10 专家重合率 ≥0.6、
专家权重下 Spearman >0.8、推荐依据字段完整、淘汰原因可追溯、确定性。
