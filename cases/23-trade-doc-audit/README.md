# 案例23 · 外贸出货单↔报关单审查 Bot（LLM 抽取 + 确定性规则引擎 + 飞书落地）

> 场景：出口贸易审单（出货单/装箱单 ↔ 海关出口报关单）· 技术主题：LLM 结构化抽取 / 确定性规则引擎 / 两单交叉对齐 / IM Agent 落地
> 方法论标签：数字判断不经过 LLM（可复现）、Agent 落地到业务 IM、规则与语义分工

## 业务背景

外贸出货流程中，业务员出货前要把**出货单/装箱单**与**报关行的出口报关单**逐项核对：
数量、单价、总价、毛净重、件数、HS 编码、收发货人、目的港、合同号……任何一处不一致
（毛重不符、数量短装、HS 归类错位、单价×数量≠总价、币制写错）都会导致退单、补税甚至
查验扣货。人工核对一票 10~30 分钟，疲劳时漏检率高，且审查过程不留痕。

## 技术问题

两份**异构单据**（Excel/PDF/扫描照片 ↔ 报关单 PDF）的对齐审查：

1. 结构审查：字段完整性（必填）、格式（HS 编码 8-10 位、币制三位代码）、算术自洽（单价×数量≈总价、表体合计=单据合计、毛重≥净重）；
2. 对齐审查：总量（毛净重/件数/金额）与行级（品名匹配后数量、HS 逐位）两单一致；
3. 落地：业务员在飞书里发文件即可，零学习成本，审查结果可追责。

核心矛盾：**抽取必须用 LLM（异构格式），但判断不能靠 LLM**（模型心算金额不可复现）。

## 方案（solution.py / engine/）

**LLM 只做抽取与语义复核，23 条规则全部确定性执行**：

- **抽取层**：`parse` 把 Excel/PDF 解析成"原文网格 + 归一化提示"（中英列名映射、
  抬头 key:value 抓取、合计行按列对齐吸收），LLM 按严格 Schema 补全为标准 JSON，
  纪律是"缺失字段必须填 null，由规则报缺失，禁止模型猜数字"；
- **规则层**（`engine/checks.py`，S1-S9 报关单结构/算术 + P1-P4 出货单结构 + A1-A10 两单对齐）：
  - 算术：每项单价×数量≈总价（容差 0.5%）、表体合计=单据合计；
  - 对齐：品名+HS 前 6 位贪心一对一匹配后核对数量/单位/HS 逐位；总量对齐带容差
    （毛净重 ±0.5kg 或 ±0.5%、金额 0.5%），CIF/CFR 运保费口径自动降级为提示；
  - 语义分工：中英双语公司名（`Ningbo XX Co., Ltd.` vs `宁波××有限公司`）确定性比对
    必然失配，**自动降级为 info 交 LLM/人工复核**而不是误报 warning——判断归属明确；
- **落地层**：基于 [pi agent](https://pi.dev) + `pi-feishu-lark`（飞书 WebSocket 长连接，
  免公网 IP），并附一个补丁使其支持 Excel/PDF 二进制附件下载落盘（原版只支持图片/文本）。

## 实测结果（bench.py 实跑，样例注入 6 处典型申报错误）

```
样例                      结论     错误  预警  提示
好样例（两单一致）         pass      0     0    2*
坏样例（6 处注入错误）     fail      6     1    2

注入错误捕获：6/6（毛重不符 A1、数量短装 A5、HS 错位 A6、
               币制非法 S5、单价×数量不符 S8、合同号不一致 A10）
好样例误报（error/warning）：0 条
pytest：45 用例全绿（tests/ 41 + test_solution.py 4）
```

\* info 为中英双语名称降级提示，属预期设计而非误报。

## 诚实边界

- 指标基于 2 行明细的合成样例（数值仿真实 LED 灯出口场景），非生产单据统计；
  规则在真实单据上的误报率需业务数据回归；
- 规则引擎只覆盖可确定性判断的问题：品名/公司名跨语言比对、扫描件视觉抽取
  依赖 LLM 与人工复核（引擎会在 findings 里明确标注这些项）；
- 容差（金额 0.5%、重量 ±0.5kg 或 ±0.5%）是默认口径，需按业务确认后调整；
- 免审权限开通依赖飞书企业自建应用身份，跨组织需各自部署。

## 复现

```bash
pip install -r requirements.txt        # openpyxl / pdfplumber / pytest

python bench.py                        # 实跑上述指标表
pytest .                               # 45 用例
python -m engine.audit_cli audit samples/packing_bad.json samples/declaration_bad.json
```
