# 案例22 · 跨境电商补货与广告联动（库存模拟回测）

> 对应《Datawhale FDE 案例 100》NO.22「从库存割裂到业务联动」· 技术主题：库存策略 / 蒙特卡洛回测 / 业务联动建模
> 方法论标签：不重造算法、保留客户公式、库存影响广告的链路联动、效果基线设计

## 业务背景（原案例）

十几人的东南亚服装跨境电商，SKU 以千计：补货靠人工从 SaaS 扒数据填 Excel 再套公式，
广告与库存完全割裂——**SKU 断货了广告还在烧钱**，客户下单却发不出货。

## 技术问题

在 200 SKU × 240 天的同一需求流上回测三种策略，验证两件事：
1. 把人工补货逻辑换成 (s, Q) 再订货点策略能省多少；
2. 在此之上，"库存跌破提前期需求 → 暂停广告"的联动还能再省多少。

## 方案（solution.py）

逐日事件驱动模拟：在途到货（同步核销）→ 需求实现（未满足即丢失）→ 补货决策 →
广告开关。三种策略：

| 策略 | 补货 | 广告 |
|---|---|---|
| `ManualBulk` 人工现状 | 每 30 天按近 90 天均值补足 90 天覆盖，无安全库存 | 断货照常投放 |
| `StaticROP` 经典 ROP | 再订货点 = μ·LT + 1.65·σ·√LT | 断货照常投放 |
| `AdaptiveROP` 优化 | 滚动需求重估 + 安全库存 | 库存 < 0.9×提前期需求 → 暂停（需求因子 0.6） |

工程细节：近窗均值与全程均值**混合估计 μ**，缓解断货期"需求被截断→估计塌缩→
不再补货"的死亡螺旋；三种策略共用同一需求流（公共随机数），对比公平。

## 实测结果

```
策略                   满足率    缺货天数   平均库存   断货期广告浪费  总成本(元)  成本降幅
人工月度补货(现状)       94.0%     3113     50632      93390      1837052    0.0%
经典ROP(广告割裂)       94.1%     2883     10753      86490       879129   52.1%
ROP+广告联动(优化)      95.8%     2444     12895          0       617342   66.4%
```

复现：`python cases/22-replenishment-ads/bench.py`

**结论**：经典 ROP 相对人工月度补货总成本 -52.1%（主要来自库存减 79%）；叠加
库存-广告联动再降 29.8%（累计 -66.4%），断货期无效广告花费归零、满足率最高
95.8%。代价与边界：广告刹车使有效需求下移 17.4%，其中大部分是本就难以履约的
无效曝光；真实系统应把暂停的预算转投给有货 SKU——这正是原案例"效果基线要
在上线前设计好"的原因，本回测脚本本身就是那份基线。

## 测试

`pytest cases/22-replenishment-ads` 覆盖：指标良构性（库存非负/满足率有界）、
ROP 满足率超过人工补货、联动版断货期广告浪费砍半以上、联动版总成本最低、
公共随机数公平性（非联动策略需求流一致）、同种子确定性。
